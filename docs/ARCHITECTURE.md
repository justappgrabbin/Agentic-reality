# Architecture contract (initial)

## World as authority
One persistent world owns entities, agent identities, position, relationships, environment, event log, and authoritative state transitions. Activities/game grammars interpret this state and submit validated actions. A game cannot quietly fork the canonical identity or event history.

## Dual aspects
1. Identity, position and context remain stable and addressable.
2. Expression, perspective and function can morph by participant, host world, activity and situation.

Public spaces have shared presentation. A visitor to a host's world sees the host's expression while retaining their own autonomy and identity.

| Scene scripting and video memory | Autonove, Video Lab, micro-drama and studio archives |

This is an **integration hypothesis**, not a claim that the APIs already interoperate.

## First end-to-end event
1. Load canonical world and one autonomous agent.
2. Enter an activity using a Klein game grammar.
3. Perform a meaningful action that emits a typed world event.
4. Validate and apply the event to the authoritative world.
5. Open a second activity and observe the changed state.
6. Restart and verify stable agent ID, relationships, state and event provenance.

## Research boundaries
Gate/chain mappings are configurable hypotheses with traceable source and evaluation data. Do not hard-code speculative correlations as established physical laws. Scenarios can be authored or generated, while agents retain independent decision logic.
